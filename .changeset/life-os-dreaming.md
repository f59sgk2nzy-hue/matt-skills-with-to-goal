Add `life-os-dreaming`, a user-invoked productivity skill that reviews the Notion-backed Life OS for one area (Work or Personal) and returns at most four evidence-backed recommendations — repeated work to turn into a skill, stale records, duplicated effort, idle projects. It recommends only; every change goes through `life-os`'s permission gate. Adapted from a public video demo of a self-improving agent OS. Promoted into `skills/productivity/` with a plugin entry, README and Productivity-bucket listings, an `ask-matt` route, and a docs page at `docs/productivity/life-os-dreaming.md`.
