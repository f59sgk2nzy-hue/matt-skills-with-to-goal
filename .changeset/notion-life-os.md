Add `life-os`, a model-invoked productivity skill that runs the user's everyday operating system in Notion, split into separate Work and Personal areas (each with Projects, Tasks, and Records databases). It captures tasks, files, and the results of tasks and conversations through a permission gate: every Notion write is proposed and waits for an explicit yes, and any wider standing permission is honoured only as stated, never across areas. Promoted into `skills/productivity/` with a plugin entry, README and Productivity-bucket listings, an `ask-matt` route, and a docs page at `docs/productivity/life-os.md`.
